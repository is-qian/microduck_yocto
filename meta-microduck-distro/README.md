# meta-microduck-distro

The `microduck` distro (`conf/distro/microduck.conf`): poky plus the robot's
policy (systemd, NetworkManager, the default distro features a headless robot
opts out of, the services it does not run).

Depends on: openembedded-core, meta-poky.

Part of https://github.com/pollen-robotics/microduck_yocto, built with
`kas/microduck.yml`; see the repository's README.md and AGENTS.md.

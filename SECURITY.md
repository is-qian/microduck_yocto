# Security policy

Covers this repository: the microduck OS image and its layers
(`meta-microduck`, `meta-microduck-bsp`, `meta-microduck-distro`).

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

- by email to **security@huggingface.co**, or
- once this repository is public, through GitHub's private vulnerability
  reporting: the **Security** tab → **Report a vulnerability** (a repository
  security advisory).

Include what is affected (image, recipe or layer, and the commit or release),
how to reproduce it, and its impact as you understand it.
